# My Favorite Series: Prison Break

## About
**Prison Break** is an action thriller about a man who gets himself sent to prison on purpose to help his *innocent brother* escape.

## Main Characters
- Michael Scofield
- Lincoln Burrows
- Sara Tancredi
- Fernando Sucre

## Why I Like It
1. Exciting plot twists
2. Smart escape plans
3. Great characters
